# Maquette d'octobre 2026 : seulement ce qui sert

Trois écrans HTML autonomes (ouvrir dans un navigateur), validés par le propriétaire de la
maison le 18 octobre 2026. Source : canevas Claude Design « Moli — refonte du tableau de bord ».

- `accueil-ordinateur.html` (1440 px) : menu latéral réduit à ce que la maison possède, bande
  « Tout va bien », chauffage, sonnette, lumières, musique, automatismes du jour.
- `pieces-ordinateur.html` (1440 px) : une carte par pièce, température et consigne, cadenas
  sur la pièce protégée, carte « Nouvelle pièce ».
- `accueil-telephone.html` (390 px) : la même chose en une colonne, barre d'onglets en bas,
  Moli au centre.

Masqué du menu dans cette maison (le code reste ; une page revient d'elle-même dès qu'un
appareil de ce type arrive) : Salon (télé), Énergie, Solaire, Impression 3D, Plan, Carte,
Parler, Infra. Dans les pages gardées, les cartes vides sont masquées aussi : piscine, qualité
de l'air, Tempo, télécommande.
